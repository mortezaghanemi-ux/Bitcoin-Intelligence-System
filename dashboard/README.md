# Bitcoin Intelligence Dashboard

This module provides a unified dashboard for Bitcoin analysis.

Main sections:

1. Bitcoin Market Overview
2. Market Indicators
3. Market Structure
4. 7-Day Bitcoin Forecast
5. Trading Signals
6. Risk and Reward Analysis
7. Historical Performance
8. Data Quality Status

Dashboard requirements:
- Responsive design for mobile and desktop.
- Display timestamps in UTC.
- Show the latest available data.
- Clearly identify stale or unavailable data.
- Separate Forecast and Trader outputs.
- Display only valid trading candidates.
- Do not display rejected signals.
- Never present forecasts as guaranteed outcomes.
