# System Tests

This directory contains automated tests for all system components.

Test categories:
- Data collector tests
- Data validation tests
- Indicator calculation tests
- Market analysis tests
- Forecast engine tests
- Trading signal tests
- Backtesting tests
- Dashboard tests

Rules:
- Test invalid and missing data.
- Test duplicate data handling.
- Test stale data rejection.
- Test timestamp consistency.
- Test probability calculations.
- Prevent look-ahead bias.
- Run tests before production deployment.
