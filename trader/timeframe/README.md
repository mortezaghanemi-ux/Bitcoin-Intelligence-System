# Multi-Timeframe Analysis

This module combines Bitcoin market analysis
across multiple timeframes.

Supported timeframes:
- 5m
- 15m
- 1h
- 4h

Analysis components:
- Trend alignment
- Signal direction alignment
- Momentum confirmation
- Market structure confirmation
- Support and resistance alignment
- Volume confirmation
- Higher timeframe validation
- Conflicting signal detection

Rules:
- Use closed candles only.
- Never use future information.
- Use validated data only.
- Record timeframe alignment.
- Identify conflicting signals.
- Store analysis timestamps in UTC.
- Preserve historical results.
