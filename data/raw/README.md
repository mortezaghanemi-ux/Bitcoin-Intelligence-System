# Raw Data

This directory stores original data collected from external sources.

Data categories:
- Bitcoin market data
- OHLCV candles
- Derivatives data
- ETF flows
- On-chain data
- Macroeconomic data

Rules:
- Preserve original source data.
- Never overwrite historical records.
- Record collection timestamps in UTC.
- Do not store API keys or secrets.
- Validate data before further processing.
